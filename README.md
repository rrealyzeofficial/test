RƎ:ALYZE V14.3 — Hiển thị kết quả cho thí sinh

1. Sao lưu Supabase trước khi thay đổi SQL.
2. Chạy supabase/UPGRADE_V14_3_CANDIDATE_RESULTS.sql trong Supabase SQL Editor.
3. Đăng lại app.js lên GitHub Pages và làm mới trang.
4. Khi Host chuyển phòng sang Kết quả, thí sinh sẽ được đọc các phiếu đã nộp và thấy điểm tổng kết.
5. Trong giai đoạn thi, thí sinh không được đọc điểm BGK.

Chưa kiểm thử thực tế trên Supabase của bạn.
